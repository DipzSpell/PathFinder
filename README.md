# PathFinder

Career roadmaps for students in India after Class 10 and Class 12.

Stream choices, entrance exams and degree paths are scattered across a hundred tabs and
conflicting opinions. PathFinder turns a couple of answers into one chronological path:
the steps, the exams to watch, and the mistake most people make on that route.

**Live demo:** [pathfinder-rouge-beta.vercel.app](https://pathfinder-rouge-beta.vercel.app)

Two ways in:

- **"I don't know what to pick"**: pick your stage and your interests, get a recommended direction.
- **"I already know my dream career"**: name the career, get the path from stream choice onward.

There is also a `/compare` page for side-by-side comparisons of degrees, diplomas and careers.
Roadmaps are generated by Google's Gemini API and rendered as a printable timeline.

## Run it on your own computer

The whole setup takes about 5 minutes. You need three things:

| What | Why | Get it |
| --- | --- | --- |
| **Node.js 22 LTS** (or 20.19+) | Runs the app | [nodejs.org](https://nodejs.org) → download the **LTS** version |
| **Git** (optional) | Downloads the code | [git-scm.com](https://git-scm.com/downloads) |
| **Gemini API key** (free) | Generates new roadmaps | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |

Check that Node is installed by opening a terminal and running:

```bash
node -v
```

It should print `v22.x.x` or higher (or at least `v20.19.0`). On Windows, use **Git Bash**,
**PowerShell** or **Command Prompt** as your terminal.

### Step 1: Download the code

**With Git:**

```bash
git clone https://github.com/DipzSpell/PathFinder.git
cd PathFinder
```

**Without Git:** click the green **Code** button at the top of this page → **Download ZIP**,
extract it, and open a terminal inside the extracted `PathFinder` folder.

### Step 2: Install dependencies

```bash
npm install
```

This creates a `node_modules` folder. It only needs to be done once.

### Step 3: Add your Gemini API key

1. Go to [aistudio.google.com/apikey](https://aistudio.google.com/apikey), sign in with a Google
   account, and click **Create API key**. Copy it.
2. In the project folder, make a copy of `.env.example` and name it `.env`:

   **Windows (PowerShell / Command Prompt):**
   ```bash
   copy .env.example .env
   ```

   **macOS / Linux / Git Bash:**
   ```bash
   cp .env.example .env
   ```

3. Open `.env` in any text editor and paste your key after the `=` sign:

   ```
   VITE_GEMINI_API_KEY=paste_your_key_here
   ```

   No quotes, no spaces around `=`. Save the file.

> [!NOTE]
> `.env` is already in `.gitignore`, so your key will never be committed. Never paste your
> key into any other file.

### Step 4: Start the app

```bash
npm run dev
```

Open **http://localhost:5173** in your browser. That's it.

To stop the server, press `Ctrl + C` in the terminal. Next time, you only need to run
`npm run dev` again (skip steps 1–3).

## Troubleshooting

| Problem | Fix |
| --- | --- |
| `node: command not found` / `'npm' is not recognized` | Node isn't installed, or the terminal was open during installation. Install Node, then close and reopen the terminal. |
| `npm install` shows an `EBADENGINE` warning or Vite fails to start | Your Node version is too old. Install Node 22 LTS from [nodejs.org](https://nodejs.org). |
| App shows **"Missing VITE_GEMINI_API_KEY"** | The `.env` file is missing or misnamed. It must be called exactly `.env` (not `.env.txt`) and sit in the project root, next to `package.json`. On Windows, turn on *View → File name extensions* in File Explorer to check. Restart `npm run dev` after editing it. |
| **"The API key was rejected"** | The key was copied incompletely or has been deleted. Create a new one in AI Studio and paste it again. |
| Port 5173 is already in use | Vite will pick the next free port automatically. Use the URL it prints in the terminal. |
| Common careers work but new ones fail | Common results are pre-cached, so they work without a key. New ones need a valid key and an internet connection. |

## How caching works

Most visitors never trigger an API call, because results are served from two layers:

1. **`src/data/seed.json`**: 48 pre-generated entries covering the 20 most-asked careers, all
   stage × interest combinations, and 10 common comparisons. Committed to the repo and
   code-split into its own chunk, so it loads on demand rather than on first paint.
2. **`localStorage`**: anything a visitor generates themselves, reused on their next visit.
   Capped at 80 entries (oldest evicted first) with a 30-day expiry per entry.

Lookups are normalised, so `Doctor`, `doctor` and ` DOCTOR ` share one entry, and a
comparison matches regardless of the order the options were picked in.

> [!IMPORTANT]
> Re-run `npm run seed` before each admissions cycle. Exam dates, cutoffs and eligibility
> change every year, and a stale cache would quietly recreate the exact problem this site
> exists to solve. As a backstop the app stops trusting `seed.json` once it is more than six
> months old (`SEED_TTL_MS` in `src/cache.js`) and falls back to live requests.

## Deploying

`npm run build` produces a static `dist/` folder that any static host will serve.

Routing is client-side, so the host must rewrite unknown paths to `index.html`. Otherwise
`/about` and `/privacy` return 404 when opened directly or refreshed. Configs for the two
common hosts are already included: `public/_redirects` (Netlify, Cloudflare Pages) and
`vercel.json` (Vercel). On Nginx use `try_files $uri /index.html;`; on Apache, an `.htaccess`
rewrite to `index.html`.

On Vercel or Netlify, add `VITE_GEMINI_API_KEY` under the project's **Environment Variables**
settings instead of uploading a `.env` file.

If you fork this project, update `CONTACT_EMAIL` and `SITE_NAME` in `src/siteConfig.js`.

> [!WARNING]
> `VITE_*` variables are inlined into the client bundle at build time, so a deployed site
> ships your Gemini key to every visitor who opens devtools. That is fine for local use and
> demos, but before putting this on a public URL, move the Gemini call behind a small server
> route (or a serverless function) that holds the key and proxies the request. `src/gemini.js`
> is the only file that talks to the API, so it is a contained change.

```

  _redirects               SPA rewrite for Netlify / Cloudflare Pages
  logo-icon.png

  main.jsx                 entry point
  App.jsx                  router, layout, sticky header
  siteConfig.js            contact email, site name, analytics flag
  gemini.js                API call + cache orchestration
  prompts.js               system instructions and prompt builders (shared with the seed script)
  normalize.js             coerces model JSON into a guaranteed shape
  cache.js                 cache keys, localStorage LRU/TTL, seed lookup
  data/seed.json           pre-generated common results
  useReveal.js             scroll-reveal sweep
  index.css                theme tokens, animations, print stylesheet
  assets/                  logo
  pages/
    Home.jsx               the tool: screen state machine, request lifecycle
    Compare.jsx            side-by-side comparison: picker + results
    About.jsx              what it is and what it is not
    Privacy.jsx            reads from siteConfig (ANALYTICS_ENABLED)
    Terms.jsx              plain-spoken terms
    Contact.jsx            email card
    NotFound.jsx           404
  components/
    Landing.jsx            entry screen, flow picker
    ForwardForm.jsx        stage + interests input

    ComparisonTable.jsx    the side-by-side grid
```

Routes: `/` (the tool), `/compare`, `/about`, `/privacy`, `/terms`, `/contact`.

## Notes

- Roadmaps are AI-generated. Exam dates, cutoffs and eligibility change every cycle, so always
  confirm against the official board or exam authority before acting on them.
- Salary figures on `/compare` are model-generated indicative ranges, not survey data. The
  system prompt explicitly forbids single-number answers and top-tier placement outliers,
  and the page carries a disclaimer. Keep both if you edit that prompt.
- "Save as PDF" uses the browser's print dialog and prints the roadmap only. App chrome and
  buttons are stripped, and steps are kept from splitting across pages. The timeline is drawn
  with borders rather than background fills, so it stays legible whether or not "Background
  graphics" is enabled in the print options.
